# 03 · 엑셀 보고서 자동화

지점마다 양식이 다른 매출 파일을 받아 **정규화 → 검증 → 통합 → 보고서**까지 한 번에 처리합니다.

```bash
python make_sample_data.py   # input/ 에 '현실적으로 지저분한' 예시 파일 5개 생성
python excel_report.py       # output/매출_통합보고서.xlsx
```

**입력에 일부러 넣어둔 문제**

- 컬럼명 제각각: `일자`/`날짜`/`판매일`/`거래일자`, `금액`/`매출액`/`total`/`합계` …
- 날짜 형식 4종: `2026-09-03`, `2026.09.03`, `20260903`, 엑셀 날짜 셀
- 금액 문자열: `12,000원`, `₩12,000`
- 표 위 제목 행, 빈 행, 중복 행, 금액 오타, 날짜 칸 `미정`, 반품(음수 수량)
- CP949 로 저장된 CSV

**보고서 시트**

| 시트 | 내용 |
|---|---|
| 요약 | KPI 5개 · 지점별 매출(가로 막대 차트) · 월별 추이(꺾은선 차트) |
| 지점×월 | 피벗 + 색상 스케일 조건부 서식 |
| 상품 순위 | 매출·수량·비중 + 요일별 일평균 매출 차트 |
| 정제 데이터 | 통합된 원장 (필터·틀고정) |
| 검증 로그 | 원본 파일·행 번호별 처리 내역 |

실무 파일에 적용할 때는 `ALIASES` 에 컬럼명만 추가하면 됩니다.
